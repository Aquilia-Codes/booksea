<h1 align="center">BOOKSEA</h1>

## The main idea of Booksea

Booksea is a managment system for boats (can be used for kayaks, surfboards, etc.). It is designed to help owners and renters to manage their bookings and other related activities (payments, tickets, etc.).

---
Basic functionality includes:
- Multi-user access (owner, renter, admin)
- Multi-boat access (one owner can have multiple boats)
- Tour management (creating, editing, and deleting tour types with associated prices and descriptions)
- Multi-language support (Croatian, English, etc.)
- Calendar of the year with availability of the boat
- Notifications (WhatsApp, SMS, Email)
- Booking system
- Guest management (for boats)
- Tour & guest search (by name, registration number, etc.)
- Ticket system (for boats & guests [qr codes])
- Filtering and sorting
---
Extra features include:
- Payment & POS gateway integration
- Data export (csv, pdf, etc.)
- Data import (csv, pdf, etc.)
- Data backup & restore 
- Tour status management (active, upcoming, past) with visual indicators (e.g., pins or color-coding)
- Real-time tour status updates and notifications 
- Analytics reports
